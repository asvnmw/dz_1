# Library Service

Сервис выдачи книг в библиотеке. Курсовая по оптимизации клиент-серверных приложений.

## Установка

Нужны Python 3.13 и PostgreSQL 16.

```
git clone https://github.com/asvnmw/dz_1.git
cd dz_1
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m scripts.init_db
python -m scripts.seed small
uvicorn main:app --reload
```

Перед запуском впиши пароль от PostgreSQL в `.env`.

## 📂 Нагрузочные тесты (k6)

Тесты написаны на [k6](https://k6.io/) и находятся в каталоге [`load/`](load/).

### Структура тестов

* `load/test.js` — **смешанный профиль**. Выполняет операции по весам (список выдач, фильтр, карточка, книги, читатели, сводка, выдача, возврат). Вход выполняется один раз до нагрузки. Отказы (409) внесены в ожидаемые ответы.
* `load/heavy.js` — **одиночный профиль**. Нагружает только самую тяжёлую операцию `GET /api/summary` (сводка).
* `load/step.js` — вспомогательный скрипт для запуска ступеней смешанного профиля с параметром `RATE`.
* `load/heavy_step.js` — вспомогательный скрипт для запуска ступеней тяжёлой операции.
* `load/profile.js` — скрипт для снятия профиля под нагрузкой (используется вместе с `py-spy`).

**Модель нагрузки:** открытая (`ramping-arrival-rate`), частота задается в запросах в секунду (RPS). Длительность каждой ступени — 30 секунд.
**Порог (Thresholds):** p95 < 500 мс, доля ошибок (5xx и сетевые) < 1%.

### 🚀 Как запустить

1. Убедитесь, что сервис запущен локально (например, на `http://localhost:8000`).
2. Установите k6 (если еще не установлен).
3. Запустите нужный тест из корня репозитория:

**Смешанный профиль (ступени 1, 2, 4 ... 128 RPS):**
```bash
k6 run -e RATE=1 load/step.js
