# Library Service

Сервис выдачи книг в библиотеке. Курсовая по оптимизации клиент-серверных приложений.

## Установка

Нужны Python 3.13 и PostgreSQL 16.

```
git clone https://github.com/asvnmw/dz_1.git
cd dz_1
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python -m scripts.init_db
python -m scripts.seed small
uvicorn main:app --reload
```

Перед запуском впиши пароль от PostgreSQL в `.env`.

##  Нагрузочные тесты (k6)

Тесты написаны на [k6](https://k6.io/) и находятся в каталоге [`load/`](load/).

### Структура тестов

* `load/test.js` — смешанный профиль. Выполняет операции по весам профиля. Вход выполняется один раз в `setup()`. Ответы 409 и 404 считаются ожидаемыми.
* `load/heavy.js` — одиночный профиль. Нагружает только `GET /api/summary`.
* `load/step.js` — запуск смешанного профиля по ступеням с параметром `RATE`.
* `load/heavy_step.js` — запуск тяжёлой операции по ступеням с параметром `RATE`.
* `load/profile.js` — скрипт для снятия профиля под нагрузкой (py-spy).

**Модель нагрузки:** открытая (`constant-arrival-rate`), частота в запросах в секунду (RPS). Длительность ступени — 30 секунд.
**Порог:** p95 < 500 мс, доля ошибок < 1%.
